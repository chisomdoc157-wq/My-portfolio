# My-portfolio
A frontend developer portfolio showcasing a collection of responsive, modern, and user-focused websites built for businesses, organizations, and personal projects. This portfolio highlights my skills in HTML, CSS, JavaScript, responsive web design, UI implementation, and practical integrations such as EmailJS and WhatsApp.

It features projects across different industries, including school websites, beauty businesses, and automotive websites. Each project focuses on solving real-world problems through clean design, intuitive navigation, mobile-friendly layouts, and functional user experiences.

This portfolio also reflects my ongoing growth as a developer, from building interfaces and interactive features to deploying projects with GitHub and Vercel. It serves as a showcase of what I can build and how I approach turning ideas into functional websites.
